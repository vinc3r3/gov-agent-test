# Аналитика и метрики

Цены сравниваются **без НДС, за базовую единицу** и только внутри группы «код ЕНС ТРУ + единица измерения».
Код: `backend/sql/004_mart.sql`, `backend/app/analytics/`.

## 1. Нормализация цены

```math
P = \frac{\text{itemPrice}}{f_{\text{ед}}}, \qquad
P_{\text{adj}} = P \cdot \frac{\text{CPI}(\text{база})}{\text{CPI}(t)}
```

$f_{\text{ед}}$ — перевод в базовую единицу (т → кг, м³ → л), $\text{CPI}$ — помесячный ИПЦ РК, $t$ — месяц договора.
Без поправки на инфляцию (~31% за 2024–2026) поздние договоры выглядели бы завышенными.

## 2. Fair Price

**Аналоги:** позиции договоров с тем же ЕНС ТРУ и единицей, других заказчиков. Сначала берутся аналоги
в том же городе поставки; если их меньше 5 — вся РК с региональной поправкой.

Цена каждого аналога приводится к единым условиям, затем — к условиям цели (область $o$, месяц $m$):

```math
\tilde{P}_i = \frac{P_{\text{adj},\,i}}{K_{\text{рег}}(o_i) \cdot K_{\text{сез}}(m_i)}, \qquad
\text{FairPrice} = \mathrm{median}\left(\tilde{P}_i\right) \cdot K_{\text{рег}}(o) \cdot K_{\text{сез}}(m) \cdot \frac{\text{CPI}(t)}{\text{CPI}(\text{база})}
```

Региональный коэффициент считается по разделу КПВЭД (2 знака ЕНС ТРУ) и области и «сжимается» к 1 при малой выборке:

```math
K_{\text{рег}} = 1 + \left(\mathrm{median}(r) - 1\right) \cdot \frac{n}{n + 20}, \qquad
r = \frac{P_{\text{adj}}}{\text{медиана по своему ЕНС ТРУ}}
```

Диапазон [0.7; 1.5]. Сезонный $K_{\text{сез}}$ — так же по месяцу, $\frac{n}{n+30}$, диапазон [0.85; 1.15].

**Оценка:** $\Delta = P / \text{FairPrice} - 1$.

| Отклонение | Вывод |
|---|---|
| до 15% | цена адекватна |
| 15–30% | умеренное отклонение |
| больше 30% | значительное отклонение |

Интервал справедливости — от Q1 до Q3 приведённых цен аналогов.
**Уверенность:** высокая при N ≥ 20 и IQR/медиана < 0.6, средняя при N ≥ 8, иначе низкая.

## 3. Аномалии цен

Средневзвешенная считается по **остальным** позициям группы, чтобы крупная закупка не влияла на собственный ориентир:

```math
\overline{P}_{-i} = \frac{\sum_{j \ne i} P_{\text{adj},\,j} \, Q_j}{\sum_{j \ne i} Q_j}, \qquad
\Delta_i = \frac{P_{\text{adj},\,i}}{\overline{P}_{-i}} - 1
```

Аномалия — $\Delta_i$ больше порога (по умолчанию 30%). Дополнительно: robust z-score по MAD и выброс выше $Q_3 + 1.5 \cdot \text{IQR}$.
Топ ранжируется по превышению $(P_{\text{adj},\,i} - \overline{P}_{-i}) \cdot Q_i$.
Группы меньше 5 позиций пропускаются; услуги с количеством «1» по умолчанию исключены (их цена — это сумма договора).

## 4. Завышение объёмов

По годовым планам, для пары «заказчик + ЕНС ТРУ» и года $Y$:

```math
R = \frac{Q_Y}{\mathrm{median}\left(Q_{\text{прошлые годы}}\right)}, \qquad
R_{\text{adj}} = \frac{R}{\max\left(R_{\text{коллеги}},\, 1\right)}
```

$R_{\text{коллеги}}$ — медиана роста у других заказчиков того же ЕНС ТРУ (отсекает общий тренд).
Аномалия: $R \ge 2$, $R_{\text{adj}} \ge 2$ и прирост суммы ≥ 1 млн ₸.
