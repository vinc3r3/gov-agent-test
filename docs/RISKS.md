# Риски и ограничения

## Данные

| Риск | Что сделано |
|---|---|
| У 12.6% позиций договоров пункт плана отсутствует в API, единица измерения неизвестна | единица восстановлена по типичной для ЕНС ТРУ; без единицы осталось 5.2%, они в сравнении цен не участвуют |
| Один код ЕНС ТРУ объединяет разные товары | медиана, leave-one-out, подтверждение по IQR; отклонение подаётся как индикатор риска |
| Фасовка («упаковка», «комплект») не нормализуется | сравнение только внутри одной единицы |
| Услуги с количеством «1» = сумма договора | исключены из поиска ценовых аномалий |
| «Рынок» — только 27 организаций | при малой выборке в городе — вся РК с региональной поправкой; N всегда в ответе |
| ИПЦ общий, а не отраслевой; 10–12.2026 ещё не опубликован | региональный и сезонный коэффициенты; последние месяцы помечены как оценка |
| Ошибки ввода на портале (цена партии вместо единицы) | контроль экстремальных цен в DQ; медианные метрики устойчивы |
| План 2026 ещё формируется, история объёмов — 2 года | поправка на тренд коллег, порог ×2 |

## AI-агент

| Риск | Что сделано |
|---|---|
| Выдуманные числа | LLM не считает; разделы ответа собирает код; вердикт проходит fact-check |
| Неверный инструмент или фильтр | подробные описания инструментов, правила в промпте, eval для регрессии ([EVAL.md](EVAL.md)) |
| Произвольный SQL | роль `agent_ro`: только чтение `core`/`mart`, таймаут 15 с, лимит 200 строк |
| Данные уходят во внешний LLM | для закрытого контура — on-prem модель; в облако уходят только вопрос и результаты по открытым данным портала |
| Лимиты облачных LLM | повторы при 429/503, `--resume` в eval; для продуктива — платный тариф или on-prem |
| Слабая локальная модель | рекомендуется ≥ 32B; код считает и рендерит, поэтому требования к модели ниже |

## Методика

- Отклонение цены — **сигнал для проверки**, а не доказательство нарушения.
- Порог ТЗ «> 30% от средневзвешенной» отмечает около трети позиций, поэтому ответ отдельно показывает аномалии, подтверждённые по IQR, и ранжирует их по денежному эффекту.
- Fair Price — справедливая цена в системе 27 заказчиков, а не рыночная цена РК.
