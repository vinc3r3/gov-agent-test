# Риски и ограничения

## Данные

| Риск | Влияние | Что сделано / как снизить |
|---|---|---|
| **12.6% позиций договоров ссылаются на пункты плана, которых нет в OWS** (`Plans` и `plans/view` возвращают пусто — вероятно, удалённые или перенесённые пункты) | у таких позиций нет ед. изм. | поле `RefEnstru.mkei` в API пустое, поэтому ед. изм. восстанавливается по доминирующей ед. изм. того же ЕНС ТРУ в планах (≥ 80%, ≥ 3 наблюдения; пометка `unit_source='enstru_mode'`). Это вернуло в анализ 7.8% позиций. **Остаток без ед. изм. — 5.2%**, они не участвуют в ценовых сравнениях (флаг `dq_no_unit`, контроль в DQ) |
| Один код ЕНС ТРУ покрывает разные по характеристикам товары | ложные «аномалии» (дорогая модель vs бюджетная) | медиана и leave-one-out, IQR-подтверждение, отклонение подаётся как индикатор риска; доработка: кластеризация по `name_clean`/характеристикам внутри ЕНС ТРУ (TF-IDF + HDBSCAN) |
| Фасовка («упаковка», «комплект», «флакон») не нормализуется | цены разных фасовок несравнимы | сравнение только внутри одной ед. изм.; ограничение указывается в ответе |
| Услуги/работы с количеством 1 = сумма договора | «цена» несравнима | исключены из ценовых аномалий по умолчанию |
| Выборка ограничена 27 организациями | «рынок» = эти 27 заказчиков; в некоторых городах мало аналогов | fallback на национальную выборку с региональным коэффициентом; N и scope явно в ответе; доработка — расширить загрузку аналогов по ЕНС ТРУ на всех заказчиков РК |
| ИПЦ — общий индекс, а не отраслевой | для отдельных товаров (топливо, медикаменты) инфляция иная | сезонный/региональный коэффициенты по разделу КПВЭД частично компенсируют; доработка — отраслевые индексы цен |
| ИПЦ за 10–12.2026 ещё не опубликован | приведение последних договоров — по оценке | помечено `is_estimate`, базовый месяц = последний официальный |
| Ошибки ввода на портале (цена за партию вместо единицы и т.п.) | экстремальные выбросы | проверка `extreme_price_ratio` (0.3% > 100× медианы); медианные метрики к ним устойчивы |
| План 2026 г. ещё формируется | рост объёмов 2026 может быть недооценён/переоценён | указано в ограничениях анализа объёмов |
| История объёмов — 2 года | оценка тренда неустойчива | поправка на тренд коллег (рост у других заказчиков того же ЕНС ТРУ), высокий порог (×2) |

## Источник (API OWS v3)

| Риск | Что сделано |
|---|---|
| Лимиты/недоступность API | семафор конкурентности, экспоненциальный backoff, upsert-идемпотентность, повтор в следующем часовом цикле |
| Изменение схемы ответов (поля-массивы вместо скаляров и т.п. — уже встречалось: `finYear`, `kato`) | raw хранится как jsonb; core-SQL защищён `jsonb_typeof` |

| Компрометация токена | токен только в `.env`/k8s Secret, не логируется, не попадает в git; ротация — замена секрета без пересборки |

## AI-агент

| Риск | Что сделано |
|---|---|
| Галлюцинации чисел | LLM не считает; разделы ответа рендерит код; числа вердикта проходят fact-check с повторной попыткой и пометкой ⚠ |
| Неверный выбор инструмента/параметров | явные описания инструментов, lookup-инструменты для ЕНС ТРУ/БИН, трасса вызовов в UI и `ops.qa_log`; eval-набор для регрессии. В eval встретились оба случая: SQL по объявлениям вместо лотов и выдуманный фильтр по году. Исправлены описанием таблиц и правилом в промпте (см. [EVAL.md](EVAL.md)) |
| Произвольный SQL | отдельная роль БД `agent_ro`: только SELECT на `core`/`mart`, read-only по умолчанию, таймаут 15 с; плюс проверка в коде (один SELECT, лимит 200 строк). Попытки записи и чтения `raw`/`ops` проверены тестом |
| Утечка данных во внешний LLM | для закрытого контура — `LLM_PROVIDER=openai_compat` с vLLM/Ollama on-prem. В облачный LLM (Claude, Gemini и т.п.) уходят только вопрос и результаты инструментов (агрегаты и top-k договоров из открытого портала); токен OWS и доступ к БД модели не передаются |
| Качество локальной модели | малые модели (7B) хуже выбирают инструменты и пишут на казахском; рекомендуется ≥ 32B (Qwen2.5-32B/72B) на vLLM; архитектура (код считает и рендерит) снижает требования к модели |
| Отказ модели (safety) | серверный fallback Claude на другую модель; при отказе — явное сообщение |
| Лимиты и перегрузки облачных LLM | бесплатный тариф Gemini — 20 запросов в сутки на модель, при перегрузке возвращается 503. Клиент повторяет запрос (`OPENAI_COMPAT_MAX_RETRIES`), eval умеет продолжать с места остановки (`--resume`). Для продуктива нужен платный тариф или on-prem модель |

## Методические ограничения

* Отклонение цены — **индикатор риска для проверки**, а не доказательство нарушения.
* Порог ТЗ «больше 30% от средневзвешенной» отмечает около трети позиций: внутри одного кода ЕНС ТРУ встречаются товары разного класса. Поэтому в ответе отдельно показано, сколько аномалий подтверждено ещё и выбросом по IQR, и ранжирование идёт по денежному эффекту.
* Fair Price опирается на фактические цены 27 организаций; это «справедливая цена в системе этих заказчиков», а не рыночная цена РК.
* Региональный коэффициент считается на уровне области и раздела КПВЭД — внутри области различия городов не учитываются (кроме выборки «тот же город»).
