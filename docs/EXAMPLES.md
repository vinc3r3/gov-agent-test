#### Метрика оценки
Рост = количество в целевом году / медиана количества за прошлые годы. Рост у коллег = медиана роста у других заказчиков того же ЕНС ТРУ. Скорректированный рост = рост / max(рост у коллег, 1). Аномалия — рост и скорректированный рост не ниже порога, а прирост суммы не меньше min_amount.

#### Ограничения и уверенность
- Уверенность: **высокая** (N сравнения = 5877; история ≤ 2 лет)

- История — не более 2 предыдущих лет (2024–2025): при одном годе истории оценка менее устойчива.
- Объём сравнивается в базовых ед. изм.; смена единицы измерения между годами (шт → упаковка) может давать ложный рост.
- Рост может быть обоснован (новые подразделения, нормативы) — результат является индикатором для проверки.
